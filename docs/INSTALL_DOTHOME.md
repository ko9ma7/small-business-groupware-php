# 닷홈 무료호스팅 설치 설명서

개발 지식이 많지 않아도 설치할 수 있도록 화면에서 해야 할 일을 순서대로 정리했습니다.

## 1. 닷홈 무료호스팅 준비

1. [닷홈](https://www.dothome.co.kr/)에 가입합니다.
2. [무료호스팅 신청](https://www.dothome.co.kr/web/free/index.php)에서 서비스를 신청합니다.
3. PHP 버전은 `8.2` 또는 `8.4`를 권장합니다.
4. 신청 후 `마이닷홈 → 호스팅 관리 → 웹호스팅 목록 → 상세보기`를 엽니다.
5. 다음 정보를 메모합니다.
   - 기본 제공 도메인
   - FTP 아이디와 비밀번호
   - DB명, DB 아이디와 DB 비밀번호

무료호스팅의 제공량과 PHP/MySQL 버전은 변경될 수 있으므로 신청 전 [공식 사양](https://www.dothome.co.kr/web/free/index.php)을 다시 확인하세요. 닷홈 공식 안내에 따르면 무료호스팅은 6개월마다 연장 신청이 필요합니다.

## 2. DB 연결 파일 만들기

배포 폴더에서 `db_conn.example.php`를 복사해 이름을 `db_conn.php`로 바꿉니다.

```php
$host = 'localhost';
$db_name = '닷홈 DB명';
$db_user = '닷홈 DB 아이디';
$db_pass = '닷홈 DB 비밀번호';
```

따옴표는 지우지 말고 안쪽 내용만 바꿉니다. 이 파일은 비밀번호가 있으므로 GitHub에 올리지 않습니다.

## 3. 데이터베이스 만들기

1. 브라우저에서 `https://내도메인/myadmin`을 엽니다.
2. 닷홈 DB 아이디와 비밀번호로 로그인합니다.
3. 왼쪽에서 제공받은 DB명을 선택합니다.
4. 위쪽 `가져오기` 메뉴를 누릅니다.
5. 파일 선택에서 `install.sql`을 선택합니다.
6. 문자셋이 보이면 `utf-8`을 선택하고 실행합니다.
7. 완료 메시지와 함께 `users`, `report_tasks`, `companies`, `site_settings`, `login_attempts`, `audit_logs` 등의 테이블이 보이는지 확인합니다.

SQL은 데이터베이스의 표와 칸을 한꺼번에 만들어 주는 설치 설계도입니다. 내용을 직접 입력할 필요 없이 `install.sql`을 한 번 가져오면 됩니다.

## 4. FTP로 파일 올리기

1. FileZilla 같은 FTP 프로그램을 설치합니다.
2. 호스트, FTP 아이디, FTP 비밀번호를 입력해 접속합니다.
3. 서버의 `/html` 폴더를 엽니다.
4. 사이트를 기본 주소에서 바로 열려면 배포 폴더 안의 파일을 `/html`에 올립니다.
5. `https://도메인/smwww/`처럼 하위 주소로 쓰려면 `/html/smwww` 폴더를 만들고 그 안에 올립니다.
6. `uploads/boards`, `uploads/documents`, `uploads/tasks` 폴더도 함께 올라갔는지 확인합니다.

닷홈의 FTP와 phpMyAdmin 접속 방법은 [공식 서비스 매뉴얼](https://www.dothome.co.kr/my/customer/manual/view.php?no=2)에서도 확인할 수 있습니다.

## 5. 첫 관리자 만들기

1. `https://내도메인/설치폴더/login.php?mode=register`를 엽니다.
2. 첫 사용자 정보를 입력해 가입합니다.
3. 데이터베이스에 사용자가 한 명도 없을 때 만든 첫 계정은 자동으로 시스템 관리자가 됩니다.
4. 로그인 후 상단의 `관리`를 엽니다.

## 6. 처음 한 번 설정하기

다음 순서가 가장 이해하기 쉽습니다.

1. `관리 → 그룹웨어 설정`
   - 그룹웨어 이름
   - 상단 보조 문구(비워 두면 실제 회사명 대신 `업무 포털` 표시)
   - 정기 회의 요일
   - 전주 실적 + 금주 계획 또는 금주 실적 + 차주 계획
   - 신규 회원가입 허용 여부
2. `조직 관리 → 회사`
   - 실제 회사명과 구분 색상 등록
3. `조직 관리 → 사업부`
   - 회사별 부서 등록
4. 직원들이 회원가입
5. `관리 → 계정/주소록`
   - 직급과 관리자 권한 확인
6. `조직 관리 → 직원 소속`
   - 회사와 사업부 배정
7. `관리 → 작업자 선택 범위`
   - 보고서 작성자가 본문에 넣을 수 있는 작업자 연결
8. `조직 관리 → 교차회사 결재선`
   - 회사가 다른 결재자도 순서대로 지정
9. 직원 등록이 끝나면 필요에 따라 신규 회원가입을 끕니다.
10. `감사 로그`를 열어 첫 로그인과 설정 변경 기록을 확인합니다.

## 7. 월요일 회의 예시

월요일에 지난주 실적과 이번 주 계획을 회의한다면 다음처럼 설정합니다.

- 정기 회의 요일: `월요일`
- 회의 자료 기준: `전주 실적 + 금주 계획`

주간 보고를 열면 두 영역에 실제 시작일과 종료일이 함께 표시됩니다. 날짜 이동도 7일 단위로 같은 기준을 유지합니다.

## 8. 문제 해결

### DB 접속 실패

- `db_conn.php`의 DB명, 아이디, 비밀번호를 다시 확인합니다.
- FTP 비밀번호와 DB 비밀번호는 서로 다를 수 있습니다.
- 닷홈 관리 화면에서 DB 비밀번호를 바꿨다면 `db_conn.php`도 같은 값으로 바꿉니다.

### 빈 화면 또는 500 오류

- PHP 버전을 8.2로 선택했는지 확인합니다.
- 파일이 `/html` 또는 의도한 하위 폴더에 완전히 업로드되었는지 확인합니다.
- `install.sql`을 올바른 DB에 가져왔는지 확인합니다.

### 이미지 첨부가 안 됨

- `uploads` 아래 세 폴더가 존재하는지 확인합니다.
- FTP에서 해당 폴더의 쓰기 권한을 확인합니다.
- 무료호스팅 디스크 사용량이 가득 차지 않았는지 확인합니다.
- 이미지는 5MB 이하 JPG·PNG·GIF·WebP인지 확인합니다.
- 일반 첨부파일은 10MB 이하 PDF·Office 문서·텍스트·CSV·이미지·ZIP인지 확인합니다.

### 로그인 시 잠시 후 다시 시도하라는 안내가 나옴

- 같은 아이디 또는 접속 주소에서 15분 동안 5회 이상 실패하면 약 15분간 로그인을 보호합니다.
- 비밀번호를 확인한 뒤 안내된 시간이 지나고 다시 시도합니다.
- 관리자는 `감사 로그`에서 정상 로그인 기록을 확인할 수 있지만 비밀번호는 기록되지 않습니다.

### 외부 메일이 안 됨

닷홈 안내상 무료호스팅은 폼메일 발송을 지원하지 않습니다. 이 프로젝트의 기본 기능은 메일 발송 없이 동작합니다.
