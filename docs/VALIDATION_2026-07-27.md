## 현재 환경에서 확인하지 못한 항목

- Docker Desktop 엔진이 시작되지 않아 실제 MySQL 컨테이너를 사용한 로그인, 게시글 작성, 일정 삭제, 결재 승인, 감사 로그 적재의 종단 간 통합 테스트는 실행하지 못했다.
- PHP 언어 서버가 설치되지 않아 LSP 진단은 실행하지 못했고, 대신 PHP CLI 전체 문법 검사를 사용했다.
- 닷홈 계정과 운영 데이터가 제공되지 않아 실제 호스팅 업로드 및 운영 DB 마이그레이션은 수행하지 않았다.

## 배포 전 운영 확인

1. 운영 DB를 백업한다.
2. `extension_schema.sql`을 적용하거나 첫 접속에서 자동 확장 스키마 생성이 성공했는지 확인한다.
3. 테스트 계정으로 로그인 실패 5회 잠금, 정상 로그인, 게시글·일정 등록과 삭제, 결재 상신과 승인, 감사 로그 적재를 확인한다.
4. 이미지 5MB, 첨부파일 10MB의 경계값과 허용되지 않은 확장자 차단을 확인한다.
5. `uploads/` 쓰기 권한과 웹 서버의 실행 파일 차단 설정을 점검한다.
