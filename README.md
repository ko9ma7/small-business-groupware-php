# 소기업용 PHP 그룹웨어

별도 서버 프로그램이나 프레임워크 없이 PHP와 MySQL만으로 운영하는 소기업용 그룹웨어입니다. 일일 업무, 주간 회의 보고, 전자결재, 게시판, 일정, 주소록과 다회사 조직 관리를 한 사이트에서 제공합니다.

운영 사례: [GROUPWARE](https://ko9ma.dothome.co.kr/smwww/index.php)

- 예시 ID: `test`
- 예시 PW: `1111`
- 운영 사례용 계정에는 실제 회사·직원·업무 정보가 보이지 않도록 권한과 공개 자료를 분리해서 사용하세요.

개인정보 없는 화면 예시: [GROUPWARE GitHub Pages 데모](https://ko9ma7.github.io/small-business-groupware-pages-demo/)

## 실제 사용 방식

이 프로젝트는 같은 경영진 아래 여러 회사가 나뉘어 있는 소규모 조직에서 시작했습니다.

- 회사와 사업부는 분리하되 경영진은 한 사이트에서 전체 보고를 확인합니다.
- 모든 직원 계정을 등록하지만 보고서 작성은 일부 관리직이 담당합니다.
- 현장 작업자 이름을 선택하면 관리자의 보고서 본문에 `이름: 작업 내용` 줄이 추가됩니다. 작업자 계정에 별도 보고서가 생기지는 않습니다.
- 일일 업무를 미리 연속 등록할 수 있고 토·일은 기본 제외합니다.
- 월요일 회의에서는 `전주 진행 실적 + 금주 예정 계획`처럼 회의 관점에 맞게 주간 보고 문구와 기간을 표시합니다.
- 회사가 달라도 결재자를 연결할 수 있습니다.

## 주요 기능

- 통합 대시보드와 오늘 업무 추적 바
- 본인 업무 및 작업자 구분형 일일 업무 작성
- 연속 일자 등록과 토요일·일요일 선택 포함
- 주간 회의용 슬라이드, 이미지 ZIP, 엑셀 출력
- 회사·사업부·직원 소속과 교차 회사 결재선
- 전자결재 기안, 승인, 반려, 보관
- 사내 게시판, 일정, 주소록, 업무 코멘트
- 맞춤법 기본 검사와 바른AI API 선택 연결
- 그룹웨어 이름, 선택형 상단 보조 문구, 가입 허용, 회의 요일과 보고 기간 설정
- 빈 상단 보조 문구에서 등록 회사명을 자동 노출하지 않는 공개정보 보호

## 권장 환경

- PHP 8.0 이상
- MySQL 8.x
- `mysqli`, `mbstring` 사용 가능 환경
- UTF-8(`utf8mb4`)

닷홈 무료호스팅은 현재 PHP 7.4/8.0/8.2/8.4와 MySQL 8.x를 지원하며 기본 상품에 디스크 500MB, 월 트래픽 15GB, 기본 도메인과 DB를 제공합니다. 소규모 내부 업무 사이트를 시작하기에 실용적인 환경입니다. 자세한 최신 사양은 [닷홈 무료호스팅](https://www.dothome.co.kr/web/free/index.php)과 [공식 무료호스팅 소개](https://docs.dothome.co.kr/books/9bf31/page/41f1f)를 확인하세요.

이 프로젝트는 닷홈의 지원이나 후원을 받아 제작된 것은 아닙니다. 무료로 실제 운영할 수 있는 기반을 제공해 준 서비스에 대한 감사와 사용 경험을 공유하기 위해 소개합니다.

## 설치

처음 설치하는 분은 [닷홈 초보자 설치 설명서](docs/INSTALL_DOTHOME.md)를 순서대로 따라 하세요.

1. `db_conn.example.php`를 `db_conn.php`로 복사하고 DB 정보를 입력합니다.
2. phpMyAdmin에서 `install.sql`을 가져옵니다.
3. 파일을 웹 루트 또는 원하는 하위 폴더에 업로드합니다.
4. `login.php?mode=register`에서 첫 계정을 만듭니다. 첫 계정은 시스템 관리자가 됩니다.
5. 관리자 메뉴에서 그룹웨어 이름, 회사, 사업부, 보고 관계와 결재선을 설정합니다.

기존 운영 사이트를 갱신할 때는 [기존 사이트 업그레이드](docs/UPGRADE.md)를 먼저 확인하세요.

## GitHub Pages 데모와 실제 운영의 차이

GitHub Pages는 PHP와 MySQL을 실행하지 않는 정적 사이트입니다. 따라서 공개 화면 체험은 [별도 Pages 데모 저장소](https://github.com/ko9ma7/small-business-groupware-pages-demo), 실제 가입·로그인·업무 저장은 이 PHP·MySQL 저장소로 분리했습니다. 자세한 이유와 선택 기준은 [두 가지 배포 방식](docs/GITHUB_PAGES.md)을 확인하세요.

## 공개 저장소 보안

`db_conn.php`, API 키 설정 파일, 첨부파일과 운영 자료는 `.gitignore`로 제외됩니다. 실제 비밀번호를 예제 파일이나 문서에 기록하지 마세요. 자세한 내용은 [보안 안내](SECURITY.md)를 확인하세요.
